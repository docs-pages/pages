TCP请求

eastspire2026/8/16小于 1 分钟tcp-requestrequestrust

GITHUB 地址

API 文档

一个 Rust 库，用于发送原始 TCP 请求，支持处理响应、管理重定向以及在 TCP 连接中处理压缩数据。

安装

通过以下命令安装该 crate：

cargo add tcp-request

注意事项

确保系统中已安装 CMake。
