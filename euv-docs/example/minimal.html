最小可工作示例

提示

本节给出一个真正能跑通的最小 euv-docs 站点——五个文件：Cargo.toml、src/lib.rs、build.rs（简化）、docs/config.toml、docs/README.md、www/index.html。克隆 euv-dev/euv-docs 可以得到完整模板。

1. Cargo.toml

[package]
name = "euv_docs"
version = "0.1.0"
edition = "2024"
description = "Minimal euv-docs skeleton."
publish = false

[dependencies]
euv = "*"
euv-ui = "*"

[build-dependencies]
pulldown-cmark = "0.12"
serde = { version = "1", features = ["derive"] }
serde_yaml = "0.9"
toml = "0.8"

[lib]
crate-type = ["cdylib", "rlib"]

2. build.rs（简化骨架）

真实模板会解析 markdown、构建 sidebar 树与路由。骨架版本只生成空 site.rs：

use std::{env, fs, path::Path};

fn main() {
    println!("cargo:rerun-if-changed=docs");

    let out_dir = env::var_os("OUT_DIR").unwrap();
    let dest = Path::new(&out_dir).join("site.rs");
    fs::write(&dest, "pub const PAGES: &[u8] = b\"[]\";\n").unwrap();
}

3. src/lib.rs

use euv::*;

mod site {
    include!(concat!(env!("OUT_DIR"), "/site.rs"));
}

#[wasm_bindgen::start]
pub fn main() {
    console_error_panic_hook::set_once();
    App::mount("#app", || render());
}

fn render() -> VirtualNode {
    html! {
        div {
            style: { padding: "24px"; font_family: "system-ui, sans-serif"; }
            h1 { "Hello, euv-docs" }
            p { "This is the minimal skeleton." }
        }
    }
}

4. docs/config.toml

[site]
title = "my-docs"
description = "Minimal euv-docs skeleton."
logo = "📘"

[[locales]]
prefix = "/"
lang = "en-US"
label = "English"
title = "my-docs"
description = "Minimal euv-docs skeleton."
footer = "MIT"
toc_label = "On this page"
prev_label = "Previous"
next_label = "Next"
navbar = [
  { text = "Home", link = "/" },
]

5. docs/README.md

---
home: true
heroText: my-docs
tagline: A minimal euv-docs skeleton.
actions:
  - text: Get Started
    link: /guide/
    type: primary
features:
  - icon: 📝
    title: Markdown-driven
    details: Write plain .md files under docs/.
  - icon: 🦀
    title: Rust + WASM
    details: The whole site is a single euv WASM app.
footer: MIT
---

## Welcome

This is the home page body. Everything above the rule comes from frontmatter;
everything below is regular markdown.

6. www/index.html

<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>my-docs</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module">
      import init, { main } from './pkg/euv_docs.js';
      await init();
      main();
    </script>
  </body>
</html>

构建与运行

# 开发
euv run --dev --port 8080 -- --target web --out-dir www/pkg --out-name euv_docs --no-typescript --no-pack

# 生产
euv build --release -- --target web --out-dir www/pkg --out-name euv_docs --no-typescript --no-pack

打开 http://127.0.0.1:8080 即可看到首页。完整的构建产物位于 www/，可直接托管到任意静态服务。

提示

这个最小骨架刻意省略了 markdown 解析、docs/public/ 静态资源拷贝、多语言切换、暗黑模式等能力——它们都依赖模板内置的 build.rs 与 euv-ui 组件库。想要完整能力请直接克隆 euv-dev/euv-docs 模板。
