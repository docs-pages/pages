Logo 品牌

eastspire2026/9/5小于 1 分钟euvuirustwasmcomponent-library

euv_logo

品牌 Logo 组件，显示渐变背景的 "E" 字母。根据 on_click 是否提供，渲染为 <button>（可点击）或 <span>（纯展示）。支持导航侧边栏和浮动操作按钮（FAB）两种变体。

Props

Props 类型: EuvLogoProps

字段类型默认值说明
variantLogoButtonVariantNav显示变体（Nav / Fab）
on_clickOption<Rc<dyn Fn(Event)>>None点击回调

LogoButtonVariant

变体说明
Nav导航侧边栏用，标准大小
Fab浮动操作按钮用，紧凑型

基本用法

use euv_ui::*;

// 导航侧边栏 Logo（无点击事件，渲染为 span）
html! {
    euv_logo {
        variant: LogoButtonVariant::Nav
    }
}

// 带点击回调的可点击 Logo
html! {
    euv_logo {
        variant: LogoButtonVariant::Nav
        on_click: Some(Rc::new(move |_: Event| {
            // 处理点击
        }))
    }
}

vConsole FAB 变体

use euv_ui::*;

html! {
    euv_logo {
        variant: LogoButtonVariant::Fab
        on_click: Some(Rc::new(move |_: Event| {
            // 打开 vConsole 面板
        }))
    }
}

提示

euv_logo 支持通过 children 传入额外内容，会显示在 "E" 字母之后，适合在 Logo 旁附加徽章或通知标记。
