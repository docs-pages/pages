HTTP类型

eastspire2026/9/4小于 1 分钟http-typetyperust

GITHUB 地址

API 文档

一个全面的 Rust 库，为 HTTP 操作提供必要的类型。包括核心 HTTP 抽象（请求/响应、方法、状态码、版本）、内容类型、Cookie、WebSocket 支持以及线程安全的并发类型（ArcMutex、ArcRwLock）。还提供了方便的 Option 包装的原始类型，以实现灵活的 HTTP 处理。

安装

要使用此 crate，可以运行以下命令：

cargo add http-type
